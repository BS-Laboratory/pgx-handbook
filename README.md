# คู่มือเภสัชพันธุศาสตร์ (PGx Handbook)

หนังสือเรียนภาษาไทยด้านเภสัชพันธุศาสตร์ (Pharmacogenomics) เรียบเรียงให้เข้าใจง่าย
ครอบคลุมตั้งแต่พื้นฐาน DNA และยีน ไปจนถึงการประยุกต์ใช้ข้อมูลพันธุกรรมกับการใช้ยาในทางคลินิก

## 📖 อ่านหนังสือออนไลน์ (ฉบับเว็บ แยกเป็นบท ๆ)

### 👉 https://bs-laboratory.github.io/pgx-handbook/

## ผู้จัดทำ

**เรียบเรียงโดย**
นางสาวภูริชญา เชื้อชาติ · นางสาวณัฐกาญจน์ ศิริพรพันธ์
นักศึกษาชั้นปีที่ 4 สาขาวิชาเทคโนโลยีชีวภาพ คณะวิทยาศาสตร์ประยุกต์
มหาวิทยาลัยเทคโนโลยีพระจอมเกล้าพระนครเหนือ

**อาจารย์ที่ปรึกษา**
ผู้ช่วยศาสตราจารย์ ดร. นายแพทย์ภูมิ สุขธิติพัฒน์
ภาควิชาชีวเคมี คณะแพทยศาสตร์ศิริราชพยาบาล มหาวิทยาลัยมหิดล
(Bhoom Suktitipat Laboratory)

## ข้อจำกัดความรับผิดชอบ

เนื้อหาในหนังสือจัดทำขึ้นเพื่อการให้ความรู้ มิได้มีวัตถุประสงค์เพื่อใช้ทดแทนคำแนะนำ
การวินิจฉัย หรือการรักษาจากบุคลากรทางการแพทย์ การเลือกใช้ยา การปรับขนาดยา
หรือการหยุดยา ควรอยู่ภายใต้คำแนะนำของแพทย์หรือเภสัชกรผู้ดูแล
